# 🛒 VeriCart AI

An AI-Powered E-Commerce Trust Platform that improves customer confidence through intelligent review analysis and personalized shopping assistance.

## Features
- AI-Powered Review Analysis (DeepSeek, Kimi, Hunyuan)
- Product Catalog & Search
- Shopping Cart & Checkout
- User Authentication (JWT)
- Trust Score
- AI Shopping Assistant
- Multi-language Support (English / Chinese)
- Responsive UI

## Tech Stack
- **Backend:** Java 17, Spring Boot 3, Spring Security, MySQL, Maven
- **Frontend:** Vue 3, Vite, Element Plus, Vue Router, Pinia
- **AI:** DeepSeek, Kimi, Hunyuan LLM APIs

## How to Run
### Backend
git clone https://github.com/rimshaakram123/VeriCart-AI.git
cd VeriCart-AI/backend
cp .env.example .env
./mvnw spring-boot:run

### Frontend
cd ../frontend
npm install
npm run dev
